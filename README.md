# 📱 창문 노드 & 시제 엣지 온보딩 프로토타입 (Node 1)

이 프로젝트는 학습자가 문법 공식을 인덕티브하게 조합하는 오류를 차단하고, 구체적인 현실 상황 맥락 속에서 **시제 엣지(Tense Edge)**를 직관적으로 추론해 나가도록 유도하는 온보딩 시연용 모바일 웹 데모입니다.

## 🎯 설계 핵심 메커니즘

1. **Deductive Node (디덕티브 노드)**: 이론 습득 없이 바로 구체적인 대표 표현 액티비티를 경험합니다.
2. **Tense Edge (시제 엣지)**: 시각적인 상황 변화 인터랙션을 통해 시점 간의 인과 및 상관관계를 스스로 연결하도록 유도합니다.
3. **CCQ 검증**: 규칙에 메이지 않고 유저가 현재 맥락을 명확히 활성화했는지 체크 질문으로 연산을 강제 교정합니다.

## 🛠️ 개발 스프린트 & 아키텍처

* **Pure CSS 애니메이션**: 이미지 리소스를 최소화하여 단일 웹 리소스 환경에서 즉각적인 애니메이션(비 내리는 효과)을 보장합니다.
* **구조 분리**: 유지보수성과 확장성을 위해 HTML, CSS, JavaScript 스크립트를 개별 파일로 설계했습니다.

## 🚀 실행 및 테스트 방법

1. VS Code에서 해당 폴더를 오픈합니다.
2. `Live Server` 확장 프로그램을 가동하여 로컬 환경에서 테스트합니다.
3. 빌드가 완료되면 파일들을 `Netlify Drop` 또는 `GitHub Pages`에 연동하여 상용 배포 링크를 확보합니다.
