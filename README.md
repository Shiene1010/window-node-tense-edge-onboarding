# 🌦️ 시제 엣지(Tense Edge) 인지언어학 온보딩 프로토타입

이 프로젝트는 학습자가 문법 공식을 기계적으로 짜 맞추는 오류를 차단하고, 구체적인 현실 상황 맥락을 터치하고 청취하며 시제 간의 연결고리인 **'시제 엣지(Tense Edge)'**를 직관적으로 추론하도록 유도하는 온보딩 시연용 모바일 웹 데모입니다.

---

## 🧠 설계 핵심 메커니즘 (Cognitive Linguistics)

1. **Deductive Node (디덕티브 노드)**
   * 지루한 문법 이론 설명 없이, 사용자가 구체적이고 현실적인 시각·청각 액티비티를 마주하며 대표 시제 표현을 정서적으로 먼저 수용합니다.
2. **Tense Edge (시제 엣지)**
   * 시공간과 상황 변화 인터랙션을 통해 시점 간의 인과관계 및 흔적을 추적하여 시제의 본질적 경계를 스스로 링크하도록 설계되었습니다.
3. **Concept Checking Questions (CCQ 검증 패널)**
   * 단순 번역이 아닌 "지금 이 순간 일어나는 일인가?"와 같은 인지적 체크 질문을 던져 규칙 변형 오류를 실시간으로 교정합니다.

---

## 🎬 시나리오 및 노드 구조 (Sprint Progress)

* **[NODE 1] 현재진행형 노드 (아파트 베란다 맥락)**
  * **타겟 표현:** `"It's raining outside right now."`
  * **메커니즘:** 아파트 창문의 커튼을 치는 순간 물리적 폐쇄가 풀리며 웅장한 실시간 빗소리가 확 쏟아지듯 부드럽게 증폭됩니다.
* **[NODE 2] 과거형 노드 (등교 후 교실 상황 맥락)**
  * **타겟 표현:** `"It was raining this morning."`
  * **메커니즘:** 비는 그치고 해가 떴으나 교실 바닥에 고인 **물웅덩이(Water Puddles)**라는 과거의 물리적 흔적과 저역대로 둔탁하게 깎인 빗소리의 오디오 잔상을 통해 과거 시제를 결과적 상태로 인지합니다.
* **[NODE 3] 미래 예측 및 조건 노드 (하교 직전 교실 맥락)**
  * **타겟 표현:** `"If it keeps getting darker, it is going to rain again."`
  * **메커니즘:** 갑자기 먹구름이 몰려오고 번개가 치는 기후 전조 현상 속에서 대기압과 기류가 가속되는 오디오 긴장감(Tension Synth)을 연출하여, 확신에 가득 찬 미래 시제의 양태를 결속시킵니다.

---

## 🛠️ 기술적 아키텍처 특장점 (Technical Architecture)

* **Pure Web Audio API 신디사이저 엔진**
  * 외부 `.mp3` 또는 외부 에셋을 전혀 로드하지 않습니다. 실시간 화이트 노이즈 버퍼 소스를 생성한 뒤 `BiquadFilterNode`의 주파수 차단 자동화(`exponentialRampToValueAtTime`)와 주파수 변조 신스(`Drip Synth`, `Tension Oscillator`) 조합만으로 날씨와 시공간의 시제 변화를 실시간 합성합니다.
* **Pure CSS 그래픽스 및 마이크업**
  * 해가 뜨는 하늘, 물웅덩이, 창틀 프레임, 빗방울 잔상, 거세지는 스톰 입자 및 번개 플래시 효과를 순수 CSS 애니메이션 키프레임으로 제어하여 리소스 성능을 극대화했습니다.
* **무결성 구조 분리**
  * 프로젝트의 확장성과 정비성을 확보하기 위해 `index.html`, `style.css`, `script.js`의 독립 구조를 완벽하게 유지합니다.

## 🚀 실행 및 테스트 방법

1. **환경 준비:** VS Code(Visual Studio Code)에서 프로젝트 루트 폴더를 오픈합니다.
2. **로컬 실행:** VS Code 내 **Live Server** 확장 프로그램을 가동하여 웹 브라우저(`localhost:5500`) 환경에서 테스트합니다.
   * *주의:* 브라우저의 미디어 자동재생 금지 정책(Autoplay Policy) 우회를 위해 화면의 **[체험 시작하기]** 오버레이 버튼을 명확히 터치해야 오디오 컨텍스트가 안전하게 초기 가동됩니다.
3. **디버깅 모드:** 브라우저 개발자 도구(`F12`)의 **Console(콘솔) 탭**을 통해 웹 오디오 신스 가동 및 시제 노드 전환 로그를 실시간으로 모니터링할 수 있습니다.
4. **배포:** 빌드 과정 없이 Netlify Drop 또는 GitHub Pages에 독립 소스 폴더를 연동하면 즉시 상용 데모 배포 링크를 확보할 수 있습니다.
